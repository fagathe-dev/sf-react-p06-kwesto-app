# forms_bo — back-office kwesto

Dashboard créateur, espace Administration et formulaire participant `/s/:token` (React 19 + Vite + TypeScript, core-react, core-ts). L'application ne communique qu'avec `forms_api` (`VITE_API_URL`).

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # Vitest (sous Windows, lancer depuis un chemin « D:\… » en majuscule)
npm run build
```
